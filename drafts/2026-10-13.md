**Reading 2: Did the format grammar constraint produce a first-draft testable failure, or appear only in the editor's review notes?**

The week-one brief contained a format grammar constraint specific enough to fail — a structural specification the production team could test on a first draft before the editor reviewed it.

In the week-one production sequence, the constraint either:

Produced a first draft the writer tested against it before submission — the draft demonstrably passed or failed the constraint, and the writer knew which — meaning the constraint was in the production execution.

Or appeared first in the editor's review notes — the constraint was in the brief template, but the writer did not test the first draft against it before submission — meaning the constraint held at the specification level and reverted at the production execution level.

A constraint that appeared only in editorial review is not a production-side format grammar constraint. It is a post-production checklist item written in the brief format.

What to add to week two's production execution: a writer-side format grammar test run before the first draft is submitted. Not a second checklist. A single test: can the writer produce a draft that demonstrably passes or fails the constraint before anyone else reads it? If yes, the constraint is in the execution. If the writer cannot self-test it, the constraint is not specific enough to run as a production-side instrument — and the brief's format grammar specification needs tightening before week two's production begins.
